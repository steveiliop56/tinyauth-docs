---
title: Configuration
description: Reference on Tinyauth's configuration.
---

Tinyauth can be configured using environment variables or CLI flags. The table below provides a comprehensive list of configuration options.

:::note
  Configuration options with a `FILE_` equivalent (e.g., `TINYAUTH_AUTH_USERS`/`--auth.users` and
  `TINYAUTH_AUTH_USERSFILE`/`--auth.usersfile`) allow the `FILE_` environment variable or CLI flag to be used as
  an alternative.
:::

| Environment | Flag | Description | Default |
| - | - | - | - |
| `TINYAUTH_APPURL` | `--appurl` | The base URL where the app is hosted. | `` |
| `TINYAUTH_LABELPROVIDER` | `--labelprovider` | Label provider to use for ACLs (auto, docker, kubernetes or none to disable). auto detects the environment. | `auto` |

## Database

| Environment | Flag | Description | Default |
| - | - | - | - |
| `TINYAUTH_DATABASE_DRIVER` | `--database.driver` | The database driver to use. Valid values: sqlite, postgres, memory. | `sqlite` |
| `TINYAUTH_DATABASE_PATH` | `--database.path` | The path to the SQLite database file, or connection URL when driver is postgres. | `./tinyauth.db` |
